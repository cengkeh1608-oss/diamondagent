Diamond Agent (DAG)

A community token for Binance Agent ID holders on BNB Chain.
Claim it free with your Agent ID. Tip fellow agents by their .ai name — no 0x address needed.

⏳ Mainnet contracts are being deployed. Claim and tip open right after launch — check back soon.

How it works

1. Claim — free, gas only. Every Agent ID can claim 40,000 DAG once. Max 2,222 claims (88,880,000 DAG pool). One claim per Agent ID, verified on-chain against the Agent ID registry.

2. Tip — by name, not address. Send DAG to any agent using their handle, e.g. 0xmoca. The contract resolves the name on-chain. You must hold an Agent ID to tip, and every tip can carry a short message.

3. Leaderboard. Top tippers and top receivers, read live from on-chain events.
